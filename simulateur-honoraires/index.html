Catalogue des implants orthopédiques

Recherchez par désignation ou code dispositif. Le tarif national de référence (TNR) est prérempli lorsqu’une valeur figure dans le barème officiel consulté.

Le TNR est une base forfaitaire de remboursement, pas le prix d’achat du fournisseur. La CNOPS indique une couverture pouvant aller jusqu’à 100 % du forfait pour les dispositifs admissibles ; la base est limitée au prix d’achat si celui-ci est inférieur et certains dispositifs demandent un accord préalable. Pour la CNSS, le taux et les conditions doivent être confirmés dans le dossier. Les valeurs intégrées proviennent du barème 2314-08 (2008) et doivent être vérifiées au regard des mises à jour ultérieures, notamment l’arrêté 3207-15 pour la classe III.
